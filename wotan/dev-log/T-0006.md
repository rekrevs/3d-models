# T-0006: Initiera Git och spegla projektet privat på GitHub

**Status**: DONE | **Size**: M
**Phase**: -

## Context
2026-09-12: Användaren pausar utskriftsberedningen och ber uttryckligen om lokal
Git-initiering och privat GitHub-spegling. Inga nätlagningar hann påbörjas.
GitHub-kontot är rekrevs och rekrevs/3d-models finns inte vid kontrollen.

## Acceptance Criteria
- [x] Lokalt Git-repo med main och initial versionshistorik.
- [x] Original-STL, Blender-scener och exporter via Git LFS; övriga projektfiler med.
- [x] Privat GitHub-repo skapat och samtliga Git-/LFS-objekt uppladdade.
- [x] Remote, privat synlighet, commit-identitet och LFS-integritet verifierade.
- [x] Pausen av T-0004 och lagringsupplägget dokumenterade.

## Approach
Använd Git LFS för *.stl och *.blend. Uteslut endast OS-cache, Python-cache,
lokala virtuella miljöer och Blender-backuper. Skapa privat repo, pusha main
och verifiera även LFS från fjärrlagringen i en temporär separat klon.

## Log
Git och Git LFS 3.8.0 finns installerade. gh fungerar utanför nätverkssandboxen.
Cirka 1,3 GB stora modellfiler; originalens innehåll bevaras.

## Verification
- Initial commit: 85529344917244ffa89c2a0f3c9412d94d2b3a1b på main.
- origin: git@github.com:rekrevs/3d-models.git.
- Push laddade upp 7/7 LFS-objekt, cirka 1,3 GB, samt övriga Git-objekt.
- Separat klon från GitHub hade samma HEAD. `git lfs fetch --all origin`
  hämtade alla sju objekt från fjärrlagringen, utan delad lokal LFS-cache.
- `git lfs fsck --objects HEAD` i kontrollklonen: Git LFS fsck OK.
- Lokal `git lfs fsck`: OK; arbetskatalogen ren före denna slutliga loggändring.

### Synlighetsavvikelse
Repot skapades med `gh repo create --private`. Kontroll före uppladdning gav
isPrivate=true / PRIVATE. En senare kontroll efter uppladdning gav oväntat
isPrivate=false / PUBLIC. Orsaken är okänd. Synligheten återställdes omedelbart
med `gh repo edit --visibility private --accept-visibility-change-consequences`.
Efterföljande separat REST-kontroll gav private=true / visibility=private.
Det är inte verifierat om någon hann få åtkomst under avvikelsen.

## Outcome
Lokalt Git och privat GitHub-spegel upprättade, inklusive stora original,
arbetsmodeller och exporter. T-0004 förblir IDEA enligt användarens paus.
Slutlig dokumentationscommit pushas och kontrolleras mot remote före överlämning.
