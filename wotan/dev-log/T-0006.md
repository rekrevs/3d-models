# T-0006: Initiera Git och spegla projektet privat på GitHub

**Status**: ONGOING | **Size**: M
**Phase**: IMPLEMENTING

## Context
2026-09-12: Användaren pausar utskriftsberedningen och ber uttryckligen om lokal
Git-initiering och privat GitHub-spegling. Inga nätlagningar hann påbörjas.
GitHub-kontot är rekrevs och rekrevs/3d-models finns inte vid kontrollen.

## Acceptance Criteria
- [ ] Lokalt Git-repo med main och initial versionshistorik.
- [ ] Original-STL, Blender-scener och exporter via Git LFS; övriga projektfiler med.
- [ ] Privat GitHub-repo skapat och samtliga Git-/LFS-objekt uppladdade.
- [ ] Remote, privat synlighet, commit-identitet och LFS-integritet verifierade.
- [ ] Pausen av T-0004 och lagringsupplägget dokumenterade.

## Approach
Använd Git LFS för *.stl och *.blend. Uteslut endast OS-cache, Python-cache,
lokala virtuella miljöer och Blender-backuper. Skapa privat repo, pusha main
och verifiera även LFS från fjärrlagringen i en temporär separat klon.

## Log
Git och Git LFS 3.8.0 finns installerade. gh fungerar utanför nätverkssandboxen.
Cirka 1,3 GB stora modellfiler; originalens innehåll bevaras.
